# Демо-скринкаст админки

Скрипт Playwright проходит по сценарию и пишет видео с нарисованным курсором, ripple на кликах и подписями шагов.

## Запуск

Нужны работающие бэкенд (`:8000`) и фронт (`:5173`), скрипт проверяет `/api/health` и `/api/status`.

```bash
cd demo && npm install && npx playwright install chromium && npm run record
```

Результат: `out/demo.webm` и `out/demo.mp4` (H.264, yuv420p, если в `PATH` есть `ffmpeg`). Длина около 2:40.

## Режимы

| Команда | Что делает |
| --- | --- |
| `npm run record` | Полная запись: создаёт кампанию `test_kuznetsov_demo_<дата>_<время>`, правит и публикует её Flow 2 |
| `npm run dry` | Пробный прогон: останавливается перед первой публикацией, видео в `out/demo-dry.*` |
| `node record.mjs --dry --id=N` | Отладка редактора на уже созданной скриптом кампании N: сбрасывает её черновик и проходит шаги 3–6 |
| `--headed` | Показать окно браузера |

`DEMO_URL` меняет адрес фронта (по умолчанию `http://localhost:5173`).

## Безопасность

Песочница Keitaro общая. Скрипт пишет только в кампанию, которую создал сам: перед каждой правкой проверяет, что открыт `/campaigns/<её ID>` и имя начинается с `test_kuznetsov_demo_`. Чужие кампании на главной только просматриваются (наведение, поиск, фильтры).

## Файлы

- `overlay.js` — курсор, ripple, подписи; внедряется через `addInitScript` и следует за реальными событиями мыши.
- `record.mjs` — движения курсора (кривая Безье, ease-in-out, 500–900 мс), сценарий, запись и обрезка ffmpeg.
